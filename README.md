# أتمتة راصد اليومية على Render

يشغّل التحليل تلقائياً كل يوم عبر متصفح حقيقي (Playwright) على خادم Render.

---

## نظرة عامة على السلسلة

```
رفع بيانات Google Drive (مؤتمت عندك) 
        ↓
Render Cron Job (يومياً، وقت محدد)
        ↓
يفتح متصفح حقيقي → يحمّل راصد → يعبّئ المفاتيح → يضغط "تحميل وتحليل"
        ↓
ينتظر اكتمال التحليل والرفع إلى Supabase
        ↓
يُغلق. النتائج جاهزة على كل أجهزتك.
```

---

## الخطوات

### ١. جهّز المستودع على GitHub
- أنشئ مستودعاً جديداً (private) على GitHub، مثلاً `rasad-automation`.
- ارفع فيه الملفات الثلاثة: `run.js` · `package.json` · `render.yaml`.

### ٢. أنشئ Cron Job على Render
- افتح [dashboard.render.com](https://dashboard.render.com) ← **New +** ← **Cron Job**.
- اربطه بمستودع GitHub اللي أنشأته.
- الإعدادات:
  - **Runtime:** Node
  - **Build Command:** `npm install`
  - **Command:** `node run.js`
  - **Schedule:** `0 13 * * 0-4` (الأحد→الخميس، 4 عصراً الرياض — عدّله حسب وقت اكتمال رفع بياناتك)

### ٣. أضف المفاتيح (Environment Variables)
في صفحة الـ Cron Job على Render ← **Environment** ← أضف:

| المفتاح | القيمة |
|---|---|
| `RASAD_URL` | `https://rasidn.netlify.app` |
| `RASAD_SHEET` | رابط Google Sheet |
| `RASAD_CLAUDE` | مفتاح Claude (الجديد بعد التجديد) |
| `RASAD_SAHMK` | مفتاح سهمك (الجديد بعد التجديد) |
| `RASAD_PROXY` | رابط Apps Script (سهمك) |
| `RASAD_OWNER` | مفتاح المالك |

> ⚠️ **مهم:** جدّد مفتاح Claude وسهمك أولاً (انكشفا سابقاً)، ثم ضع الجدد هنا.

### ٤. شغّل تجربة يدوية
- في صفحة الـ Cron Job ← **Trigger Run** (تشغيل يدوي فوري).
- راقب **Logs**. المفروض تشوف:
  ```
  🚀 بدء الأتمتة...
  ⚡ ضغط زر تحميل وتحليل...
  ✅ التطبيق ظهر — التحليل جارٍ...
  ☁️ ✅ رُفعت 232 توصية إلى Supabase
  🎉 نجحت الأتمتة!
  ```
- لو ظهرت "🎉 نجحت" → الأتمتة تعمل. من الآن تشتغل يومياً تلقائياً.

## استكشاف الأخطاء

| العرض في Logs | السبب | الحل |
|---|---|---|
| `❌ RASAD_OWNER مطلوب` | مفتاح المالك غير مضبوط | أضف `RASAD_OWNER` في Environment |
| `⚠️ XLSX لم تُحمّل` | الشبكة بطيئة | عادةً يكمل؛ لو تكرّر زد المهلة |
| `⏱️ انتهت المهلة دون تأكيد الرفع` | التحليل تأخّر أو فشل الرفع | تحقّق من مفاتيح Claude/سهمك، أو زِد `RASAD_TIMEOUT` |
| `لم تظهر واجهة التطبيق` | تحميل الجلسات فشل | تأكد أن رابط الشيت صحيح وعام |

### متغيّرات اختيارية
- `RASAD_TIMEOUT` — مهلة انتظار الرفع بالملّي ثانية (افتراضي 180000 = 3 دقائق).

## التوقيت (schedule)

الصيغة بتوقيت **UTC**. السعودية = UTC+3.

| تريد التشغيل (الرياض) | اكتب في schedule |
|---|---|
| 4:00 عصراً | `0 13 * * 0-4` |
| 4:30 عصراً | `30 13 * * 0-4` |
| 5:00 عصراً | `0 14 * * 0-4` |

`0-4` = الأحد إلى الخميس (أيام تداول تداول السعودية). عدّل الساعة حسب وقت اكتمال رفع بياناتك — التحليل يجب أن يكون **بعد** رفع البيانات.
